# Spec 거절 참고 뉴스 화면 표시 개선 (날짜 형식·기사 요약)

관련: [refusal-news-search.md](./refusal-news-search.md). 서버·그래프·API 응답은 바꾸지 않는다. 화면(`backend/static/review-detail.js`, `review-detail.css`)만 바꾼다.

## Why

- **페르소나**: 거절 응답의 참고 뉴스를 보고 다음에 무엇을 할지 정하는 심사역
- **상황**: 11/12 서비스 화면 검증에서 뉴스는 나왔지만 (1) 날짜가 `Wed, 23 Sep 2026 07:02:00 +0900`처럼 영문 원문 그대로이고 (2) 제목만 보여 기사가 도움이 되는지 판단하기 어려웠다.
- **측정 지표**: 날짜가 `YYYY-MM-DD`로 보임 / 요약이 있는 기사는 제목 아래에 요약이 보임 / 기존 안전 규칙(글자 그대로, http(s) 링크만) 유지.

## Goal

- **해결 목표**: 기사 한 줄에 `제목 / 언론사 도메인 · 발행일(YYYY-MM-DD) / 요약`을 보인다.
- **성공 기준**: AC-D1~D4 통과, 기존 뉴스 화면 시험 회귀 없음.
- **Out of Scope**: 서버 응답 변경, 뉴스 선별 로직(관련 기사 걸러내기), 거절 범위 확대, LLM 요약. 요약은 네이버가 준 `description`을 자르기만 한다.

## What

| # | 상황 | 처리 |
|---|---|---|
| D1 | `pub_date`가 RFC 날짜 문자열 | 한국 시간 기준 `YYYY-MM-DD`로 표시 |
| D2 | `pub_date`를 읽을 수 없음 | 원문을 그대로 보이고 숨기지 않는다 |
| D3 | `description`이 있음 | 제목·메타 아래에 글자 그대로(`textContent`) 보이고, 120자를 넘으면 120자에서 자르고 `…`을 붙인다 |
| D4 | `description`이 없거나 비었거나 문자열이 아님 | 요약 줄을 만들지 않는다 |

**표시 순서**: 제목(링크 또는 글자) → 메타(`언론사 도메인 · 날짜`) → 요약. 기존 시험이 제목을 첫째, 메타를 둘째 자식으로 보므로 요약은 셋째로 둔다.

**안전 규칙(변경 없음)**: 모든 값은 `textContent`로만 넣고 HTML로 해석하지 않는다. 링크는 http·https만 걸고 새 탭, `rel="noopener noreferrer"`. 뉴스는 공시 근거가 아니며 초안·인용 영역에 들어가지 않는다.

## 시험 (tests/review_detail_web_ui.test.mjs)

- AC-D1: 영문 날짜가 `2026-11-10`으로 보인다(KST, UTC 경계 포함 1건).
- AC-D2: 읽을 수 없는 날짜는 원문 그대로 보인다.
- AC-D3: 요약이 제목 아래(셋째 자식)에 글자 그대로 보이고, 긴 요약은 120자 + `…`이다.
- AC-D4: 요약이 없으면 자식이 둘뿐이다.
