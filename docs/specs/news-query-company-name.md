# Spec 뉴스 검색어에서 회사명을 쪼개지 않기

관련: [refusal-news-search.md](./refusal-news-search.md), [refusal-news-after-search.md](./refusal-news-after-search.md).

> **결과(11/12) — 이 Spec의 방식(검색어에서 회사명을 쪼개지 않기)은 채택하지 않았다.** 사전 등록 측정에서 효과가 0이었고(네이버는 "한화 시스템"과 "한화시스템"을 같은 결과로 돌려준다), 원인 가설이 틀렸다.
> 큰따옴표(Q)도 기준 미충족이었다. **채택한 방식은 기사 사후 필터**다: 질문에 서비스 코퍼스 회사명이 있으면 제목 또는 요약에 그 이름이 있는 기사만 남긴다(한화오션 혼입 3건 → 0건).
> 구현은 `news_search.find_company_names`, `select_recent_items(require_any=)`, `search_news(require_company_names=)`, `build.py`의 `_default_news_search(corp_names)`이며 근거는 `docs/evidence/news_query_company_name_2026-11-12.md`, `docs/evidence/news_company_filter_2026-11-12.md`다.
> `build_news_query(company_names=, quote_company_names=)` 옵션은 서비스에서 쓰지 않고 기본값은 기존 동작이다. 아래 본문은 당시 계획 기록으로 남긴다.

## Why

- **페르소나**: 거절 응답의 참고 뉴스로 다음 단서를 찾는 여신 심사역
- **상황**: 11/12 서비스 화면 검증(한화시스템 심사 건)에서 "한화시스템의 최근 노조 파업 보도" 질문에 한화오션 하청노조·한화세미텍·엔비디아 소송 기사가 나왔다.
- **원인**: 형태소 분석기가 "한화시스템"을 "한화"+"시스템"으로 쪼개 검색어가 `한화 시스템 노조 파업`이 되고, 네이버가 "한화"가 들어간 다른 계열사 기사를 돌려준다. 같은 현상이 "SK 하이닉스", "LG 에너지 솔루션"에서도 측정으로 확인됐다(docs/evidence/news_relevance_filter_2026-11-12.md).
- **측정 지표**: 코퍼스 회사 질문에서 뉴스 제목에 그 회사 이름이 들어간 비율이 오른다. 코퍼스에 없는 회사·회사명이 없는 질문의 검색어는 기존과 같다.

## Goal

- **해결 목표**: 질문에 서비스 코퍼스 회사명이 들어 있으면 그 이름을 **한 덩어리로 검색어 맨 앞에** 두고, 나머지 낱말(최대 3개)을 기존 규칙으로 뽑는다. 예: `한화시스템 노조 파업`.
- **성공 기준**: AC-Q1~Q5 통과 / 사전 등록한 측정 기준 충족 / 검색어를 못 만들면 기존과 같다.
- **Out of Scope**: 별칭(예: "현대차")까지 넓히기, 코퍼스에 없는 회사의 이름 보존, 뉴스 정렬·선별 변경, LLM 사용.

## What

| # | 상황 | 처리 |
|---|---|---|
| Q1 | 질문에 코퍼스 회사명이 한 번 들어 있음 | 그 이름을 검색어 첫 낱말로 두고, 이름 부분을 뺀 문장에서 나머지 낱말을 뽑는다 |
| Q2 | 회사명이 여럿(부분 일치 포함) | 긴 이름부터 찾고, 찾은 부분은 문장에서 지워 중복·부분 일치를 막는다. 검색어에는 최대 2개 이름 |
| Q3 | 회사명이 없음(코퍼스 밖 회사 포함) | 기존 검색어와 완전히 같다 |
| Q4 | 이름 때문에 검색어가 30자·4낱말 상한을 넘음 | 기존 상한 규칙을 그대로 적용(이름이 우선) |
| Q5 | 이름 목록이 비어 있음(기본값) | 기존과 같다. 서비스에서는 코퍼스 카탈로그의 회사명 목록을 넘긴다 |

**구현 위치(최소)**: `backend/services/news_search.py`의 `build_news_query(question, noun_extractor=None, company_names=())`에 인자를 추가하고, 채택 시 `backend/graph/build.py`의 기본 뉴스 검색이 `corpus_catalog.corp_names`를 넘긴다.

## 시험 (tests/test_news_query_company_name.py)

- AC-Q1: 이름이 한 덩어리로 첫 낱말이 된다(주입 추출기와 실제 형태소 분석기 각각)
- AC-Q2: 긴 이름 우선, 부분 일치 중복 방지
- AC-Q3: 이름이 없는 질문의 검색어는 기존 함수 결과와 같다
- AC-Q4: 4낱말·30자 상한
- AC-Q5: 기본값(빈 목록)은 기존과 같다 / 기본 뉴스 검색이 카탈로그 이름을 넘긴다

## 작업 순서

1. Spec·사전 등록(이 문서와 증거 문서) 커밋
2. `build_news_query(company_names=)`: 실패 시험 → 최소 구현 → 커밋 (서비스 연결 전, 기본값이 빈 목록이라 동작 불변)
3. 측정(HUB만 호출): 기존 검색어 대 회사명 보존 검색어
4. 채택 기준 충족 시에만 `build.py`에 연결: 실패 시험 → 최소 구현 → 커밋
5. 전체 검증 → PR
