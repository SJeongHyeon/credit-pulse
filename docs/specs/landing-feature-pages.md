# 랜딩 로그인 상태 반영과 기능별 상세 시트

## Why

- **페르소나**: 로그인해서 랜딩(`/`)의 03 기능 패널로 심사 화면에 들어가는 기업여신 심사역.
- **상황**: 랜딩에서 로그인한 뒤에도 화면이 비로그인 때와 거의 같고, 기능 칸이 이름과 다른 곳으로 가거나 준비 중이다.
- **문제**:
  1. 랜딩에 로그아웃 버튼이 없다(`/reviews`에만 있다).
  2. 로그인 상태에서도 "로그인 후 사용 가능합니다." 문구가 남는다.
  3. 로그인 상태에서 칸을 누르면 `feature-login.js`가 로그인 창을 열어 제목뿐인 빈 박스가 보인다.
  4. 칸 5개가 이름에 맞는 화면으로 가지 않는다(공시 검색·보고서는 준비 중, 규칙은 `/reviews#rules-section`).
  5. 상세가 목록만 있어 처음 열면 비어 보인다.
- **측정 지표**: 로그인 상태 랜딩에서 로그인 창이 열리는 횟수 0, 칸 5개가 모두 이름에 맞는 시트를 연다, 시트 첫 화면에 요약 카드가 보인다.

## Goal

- **해결 목표**: 랜딩이 로그인 상태를 반영하고, 기능 5개가 랜딩 위로 **아래에서 올라오는 시트**로 열리며, 각 시트 상단에 기존 API 응답에서 집계한 요약 카드·그래프를 둔다.
- **성공 기준**: 아래 AC 전부 통과 / `tests/*.test.mjs`와 pytest 통과 / 가로 스크롤 없음(360px) / 새 외부 CDN·차트 라이브러리 0개 / 새 백엔드 엔드포인트·새 라우트 0개.
- **Out of Scope**: LLM 호출 추가, 새 API·DB 변경, 보고서 생성·내보내기·메모 본문 표시, 항목 판정(충족/미충족/확인불가) 분포(목록 API에 판정이 없어 건마다 상세 호출이 필요), 인증 API 계약 변경, 로그인 폼 문구 변경, 동결 평가셋, `/reviews`·`/approvals`·`/reviews/{id}` 전체 페이지의 재설계(그대로 둔다).

## What

### Happy Path

1. 랜딩이 열리면 `login.js`가 `GET /api/v1/auth/me`를 **한 번** 부른다(결과를 `<html data-auth>`와 `auth-state` 이벤트로 공유, 중복 호출 없음).
2. 200이면 로그인 상태다. 「로그인」을 숨기고 「로그아웃」(헤더·히어로)을 보이며, 응답의 `display_name`이 있으면 헤더에 `닉네임님`을 표시한다. 「로그인 후 사용 가능합니다.」는 숨긴다.
3. 로그인 상태에서 03 패널 띠의 「열기」를 누르면 로그인 창 없이 그 기능의 시트가 올라온다.
4. 「로그아웃」은 `POST /api/v1/auth/logout` 후 비로그인 상태 화면(로그인 버튼·안내 문구)으로 돌아온다(열린 시트는 닫는다).
5. 401이면 비로그인 상태: 「열기」 → 로그인 창 → 성공 시 그 칸의 시트가 열린다(`/?open=<기능>`으로 이동 후 시트를 열고 주소의 `open`은 지운다). 창을 닫으면 도착지는 `/reviews`로 초기화된다(칸 없이 로그인하면 기존처럼 `/reviews`).

### 03 기능 패널: 펼쳐지는 띠(시안 D)

- **모양**: 03 패널에 세로 띠 5개(`공시 검색`·`리스크 점검`·`보고서`·`승인 현황`·`내 판정 규칙`)가 있다. 닫힌 띠는 아이콘, 세로로 쓴 이름, 아래쪽 현재 수치(`100`·`6`·`6`·`2`·`4` 같은 짧은 숫자)만 보인다. 선택한 띠 하나가 넓게 펼쳐져 이름, 「열기 →」, 요약 문장, 카드, 그래프를 보인다. 처음에는 `리스크 점검`이 펼쳐져 있다.
- **펼침 모션**: 띠 폭이 부드럽게 바뀌고(약 1초), 펼쳐지는 면이 왼쪽 책등을 축으로 회전하며 열린다(`rotateY`). 열릴 때 책등 쪽 그늘과 한 번 훑는 빛이 있다. 이전 면은 닫힌다. `prefers-reduced-motion`이면 모션 없이 바로 바뀐다.
- **크기**: 띠 영역은 03 패널의 오른쪽 폭을 왼쪽으로 8rem 넓혀 쓴다(1000px 이하에서는 넓히지 않는다). 닫힌 띠 폭 3rem, 띠 사이 간격 .5rem. **높이는 25rem**이고 세로 위치는 위 끝이 배경 사진의 막대 그래프 아랫부분, 아래 끝이 03 탭 왼쪽의 자동재생(초록) 버튼 아랫부분과 같은 높이가 되게 맞춘다(뷰포트 높이 720~776px 기준). 높이가 줄어든 만큼 미리보기 여백을 압축해 5개 기능 모두 스크롤 없이 한 화면에 들어온다. 폭 800px 미만에서는 띠가 위아래로 쌓이는 아코디언이다.
- **여백·통일감**: 펼친 면 안쪽 여백을 넉넉히 두고, 카드는 폭이 모자라면 두 줄로 나누며(홀수 개면 마지막 카드를 한 줄 전체 폭으로, 4개면 한 줄 4칸) 값은 카드 밖으로 나오지 않는다. 「열기 →」와 본문의 「새 심사 건 만들기」는 같은 금색 테두리·투명 바탕 버튼이다(흰색 바탕 버튼 없음).
- **미리보기 내용**: 시트와 같은 본문 함수(`sheet-panels.js`)의 결과 중 요약 문장·카드·그래프만 보인다. 목록·검색 입력·삭제 버튼·「화면 열기」 링크는 숨기고(시트에서 한다), 빈 상태 안내는 보인다. 심사 건 집계는 시트와 한 번만 불러와 공유한다.
- **로그인 상태별**: 로그인 상태에서만 API를 부르고 수치·미리보기를 채운다. 비로그인이면 띠를 펼쳐도 기능 설명만 보이고(「로그인 후 사용 가능합니다.」 안내는 그대로), 「열기」는 로그인 창을 열어 도착지(`/?open=<기능>`)를 저장한다. 로그아웃하면 수치·미리보기를 비운다.
- **조작**: 닫힌 띠를 누르거나 Enter/Space로 펼친다. 띠 사이 ←→(↑↓)로 이동한다. 닫힌 면은 조작할 수 없다(`inert`). 03 영역에 마우스를 올리거나 포커스가 있는 동안 기존 자동 전환은 멈춘다(기존 동작).

### 시트

- **모양**: 화면 아래에서 올라오는 시트. 높이 88dvh, 위쪽 모서리 둥글게, 위 가운데 회색 손잡이 막대. 왼쪽 끝은 헤더 로고의 가로 중앙, 오른쪽 끝은 「로그아웃」 버튼의 왼쪽 끝에 맞춘다(열 때와 창 크기를 바꿀 때 측정). 폭이 480px 미만이면 전체 폭. `prefers-reduced-motion`이면 움직임 없음.
- **구성(시안 E-4)**: 왼쪽 목록(기능 5개: 아이콘, 이름, 한 줄 설명, 현재 수치)과 오른쪽 본문(선택한 기능의 이름 + 본문). 둘 사이는 위아래로 옅어지는 금빛 세로선(`--gold`)으로 나누고, 오른쪽 이름 아래에 가로선, 카드와 그래프 사이에 점선·실선 가로선을 둔다. 「닫기 ✕」는 시트 오른쪽 위 모서리에 둔다. 목록 항목을 누르면 시트를 닫지 않고 본문만 바꾼다. 시트 폭이 44rem 미만이면 목록이 위쪽 가로 줄로 바뀌고 설명·수치는 숨긴다.
- **현재 수치**(목록 오른쪽 작은 글자): 공시 검색 `N곳`(`COMPANIES`), 리스크 점검 `진행 N건`, 보고서 `저장 N건`, 승인 현황 `대기 N건`(심사 건 집계 재사용), 내 판정 규칙 `N개`(`GET /api/v1/rules`가 200일 때만). 불러오지 못하면 수치만 비워 둔다(오류 문구를 따로 내지 않는다).
- **닫기**: 「닫기」, Esc, 시트 바깥(배경) 클릭. 닫으면 연 칸으로 포커스가 돌아간다. 열려 있는 동안 뒤 화면은 조작되지 않는다(네이티브 `<dialog>.showModal()`).
- **칸 ↔ 시트**:

| 칸 | 시트 본문 |
|---|---|
| 공시 검색 | 검색 칸, 보유 기업 결과, 요약 |
| 리스크 점검 | 요약 + 최근 건 + 「심사 건 화면 열기」(`/reviews`) |
| 보고서 | 종료(`closed` = 승인·저장된) 심사 건 모아 보기 + 요약 |
| 승인 현황 | 요약 + 승인 대기 건 + 「승인 현황 화면 열기」(`/approvals`) |
| 내 판정 규칙 | 규칙 목록·삭제 + 요약 |

### 요약 집계(새 API 없음)

- **심사 건 집계**: `GET /api/v1/reviews?page_size=50`를 `next_cursor`로 최대 5쪽(250건) 받아 프런트에서 센다. 한 시트 열림 동안 결과를 재사용한다(다시 불러오기 때 다시 받는다). 5쪽을 넘으면 문장에 "최근 250건 기준"을 밝힌다. 중간에 실패하면 받은 건도 버려 틀린 숫자를 보이지 않고 오류 문구와 「다시 불러오기」만 둔다.
- **상태 정의**: 진행 중 = `open`·`running`·`awaiting_approval`·`saving`(종료가 아닌 것). 승인 완료 = `closed`(승인하면 `closed`, 취소하면 `open`).
- **리스크 점검**: 카드(전체, 진행 중, 승인 대기, 종료), 상태별 막대 그래프, 최근 건 3개(`created_at` 내림차순) 링크.
- **승인 현황**: 카드(승인 대기, 진행 가능, 처리 중, 승인 완료), 상태 도넛 그래프, 승인 대기 건 최대 5개(「승인하러 가기」 → `/reviews/{id}`).
- **보고서**: 카드(저장된 메모 건 수, 기업 수=`corp_code` 고유 수, 가장 최근 생성일), 사업연도별 막대 그래프, 종료 건 최대 10개(각 `/reviews/{id}` 링크, 「생성 YYYY-MM-DD HH:mm」). 목록 API에 저장 시각·메모 본문이 없으므로 "저장 시각"이라 적지 않고 본문을 보이지 않는다.
- **내 판정 규칙**: `GET /api/v1/rules`. 카드(규칙 수, 항목 종류 수), 항목(`item`)별 막대 그래프, 규칙 목록. 항목 이름은 `ITEM_LABELS`, 모르는 값은 "알 수 없음". 삭제는 「삭제」 → 「정말 삭제」(+「취소」) 두 단계, `DELETE /api/v1/rules/{id}`(204·404는 목록에서 제거).
- **공시 검색**: 데이터는 `landing-data.js`의 `COMPANIES`(API 없음). 카드(보유 기업 수, 검색 결과 수, 최신 공시일), 사업연도별 막대 그래프, 이름·corp_code 부분 일치 검색(공백 무시·대소문자 무시), 결과는 최대 20곳을 보이고 넘으면 "외 N곳. 검색어로 좁혀 보세요."를 보인다. 각 결과에 「심사 건 만들기」(`/reviews#create-section`).
- **빈 상태**: 심사 건이 0건이면 그래프 대신 "아직 심사 건이 없습니다." 계열 안내와 「새 심사 건 만들기」(`/reviews#create-section`)를 보인다.
- **색**: `theme.css` 토큰(`--gold`, `--gold-soft`, `--on-dark`, `--on-dark-muted`, `--glass-*`)만. 차트 라이브러리 없이 DOM + CSS(너비 %, `conic-gradient`).
- **접근성**: 그래프는 `role="img"` + `aria-label`에 요약 문장(화면에도 같은 문장을 둔다). 색만으로 구분하지 않고 이름과 숫자를 함께 쓴다. 모든 링크·버튼은 키보드로 접근한다.

### Edge Cases

| # | 상황 | 처리 방식 |
|---|---|---|
| EC-01 | `/me`가 200인데 `display_name`이 없거나 문자열이 아님 | 닉네임 표시만 생략, 로그인 상태 유지 |
| EC-02 | 랜딩의 `/me`가 401·5xx·네트워크 오류 | 비로그인 상태 화면 |
| EC-03 | 로그아웃 요청 실패(5xx·네트워크) | 로그인 상태 유지 + 랜딩 오류 문구, 다시 누를 수 있음 |
| EC-04 | 로그아웃 요청이 401 | 이미 세션이 없으므로 비로그인 상태로 전환 |
| EC-05 | `/me` 확인 중에 칸을 눌러 로그인 창이 열렸는데 곧 200 | 저장된 도착지가 있으면 그 시트로 이동, 없으면 창을 닫는다(빈 박스 금지) |
| EC-06 | 허용 목록 밖 `login-next`·`open` 값 | 무시(`/reviews` 또는 시트 없음) |
| EC-07 | 시트 안 API가 401(세션 만료) | `/`로 이동해 다시 로그인하게 한다 |
| EC-08 | 시트 안 API가 429·5xx·네트워크 오류 | 본문 영역에 고정 문구 + 「다시 불러오기」, 서버 오류 본문은 쓰지 않는다 |
| EC-09 | 심사 건 0건 | 카드는 0, 그래프 대신 빈 상태 안내 + 「새 심사 건 만들기」 |
| EC-10 | 규칙 API 503 `SERVICE_UNAVAILABLE_RULES`(데모 모드) | "이 환경에서는 판정 규칙 기억을 쓰지 않습니다(데모 모드)." (실제 키가 있는 서비스에서는 규칙이 나온다) |
| EC-11 | 검색어가 공백뿐/결과 없음 | 공백은 전체 목록, 결과 없으면 "검색 결과가 없습니다." |
| EC-12 | 서버가 준 문자열에 HTML이 들어 있음 | 모두 `textContent`로만 넣는다(`innerHTML` 금지) |
| EC-13 | 탭을 빠르게 바꿈 | 늦게 도착한 이전 탭의 응답은 버린다 |
| EC-14 | `<dialog>`를 지원하지 않는 브라우저 | `open` 속성으로 열고 닫기·Esc는 직접 처리 |

## How

- **라우트·API**: 새 라우트·엔드포인트 없음. `/`, `/reviews`, `/approvals`는 기존 그대로.
- **템플릿**: `login.html`에 `<dialog id="feature-sheet">`(손잡이, 닫기, 왼쪽 목록 `nav#sheet-tablist` 5항목, 오른쪽 이름 `h2#sheet-title`과 본문 `#sheet-body`)를 두고 03 패널의 칸 5개를 `a.feature-tile`로 바꾼다. 칸의 `href`는 `/?open=search|reviews|reports|approvals|rules`이다. 이 값이 `login-next`의 값이기도 하다. `reviews.html`의 「새 심사 건 만들기」 섹션에 `id="create-section"`을 단다.
- **허용 목록**(`feature-login.js`의 `ALLOWED`, `login.js`의 `ALLOWED_NEXT`)은 항상 같다: `/reviews`(기본 도착지), `/?open=search`, `/?open=reviews`, `/?open=reports`, `/?open=approvals`, `/?open=rules`.
- **랜딩 로그인 상태**:
  - `login.js`: `checkSession` 결과로 `<html data-auth="authenticated|anonymous">`를 정하고 `auth-state` 이벤트를 보낸다. 로그아웃 버튼(`#site-logout`, `#hero-logout`)·닉네임(`#site-user`)·안내 문구(`#login-required-hint`)를 토글한다. 새 요소가 없으면 건너뛴다. 로그아웃은 `POST /api/v1/auth/logout`.
  - `feature-login.js`: 로그인 상태이면 가로채지 않는다(시트 쪽이 연다). 비로그인이면 기존대로 로그인 창을 열고 도착지를 저장한다.
- **시트**:
  - `feature-sheet.js`: 칸 클릭(로그인 상태) 또는 `?open=`로 시트를 열고, 위치 맞춤·탭 전환·닫기·포커스 복귀·오래된 응답 버리기를 맡는다. 로그아웃 시 시트를 닫는다.
  - `sheet-panels.js`: 기능 5개의 본문을 그린다(`document.createElement`, `textContent`만).
  - `charts.js`: 요약 카드·막대·도넛·빈 상태 DOM 빌더.
  - `review-data.js`: 심사 건 전체 불러오기(최대 5쪽)와 상태 집계.
  - `feature-sheet.css`: 시트·카드·그래프 스타일(토큰만, 360px 가로 스크롤 없음).
- **제약**: LLM 호출 없음. 서버 값은 `textContent`/`setAttribute`로만. 인젝션 방어·인증 동작을 바꾸지 않는다. 동결 평가셋·`.env`를 건드리지 않는다.
- **실서비스**: 코드는 데모/실제 모드를 가리지 않고 API 응답만 따른다. 키가 있는 환경에서 규칙 API가 200이면 규칙이 보인다.

## AC (Given-When-Then)

**AC-01** · GIVEN 비로그인, WHEN `/` 접속, THEN 「로그인」 버튼과 「로그인 후 사용 가능합니다.」가 보이고 「로그아웃」은 숨겨져 있다.

**AC-02** · GIVEN 로그인, WHEN `/` 접속, THEN 「로그아웃」이 보이고 안내 문구와 「로그인」 버튼은 숨겨지며 `/me`는 한 번만 호출된다. `display_name`이 있으면 헤더에 `닉네임님`으로 표시된다.

**AC-03** · GIVEN 로그인, WHEN 03 패널 띠 5개의 「열기」를 각각 누르면, THEN 로그인 창 없이 각각 `공시 검색`·`리스크 점검`·`보고서`·`승인 현황`·`내 판정 규칙` 시트가 열리고 연 칸이 선택된 목록 항목(`aria-selected`)이다. 목록에서 ↑↓(←→)로 항목을 옮길 수 있다.

**AC-04** · GIVEN 로그인, WHEN 「로그아웃」을 누르면, THEN `POST /api/v1/auth/logout` 호출 후 비로그인 화면으로 돌아오고 열린 시트는 닫힌다. 실패하면 로그인 상태를 유지하고 오류 문구를 보인다.

**AC-05** · GIVEN 비로그인, WHEN 띠의 「열기」를 누르면, THEN 로그인 창이 열리고 도착지(`/?open=…`)가 저장되며, 로그인 성공 시 그 기능의 시트가 열린다. 창을 닫으면 도착지가 지워져 이후 로그인은 `/reviews`로 간다. 허용 목록 밖의 값은 `/reviews`다.

**AC-06** · GIVEN 로그인 확인 중 로그인 창이 열렸고, WHEN `/me`가 200이면, THEN 빈 박스를 남기지 않고 저장된 도착지로 이동하거나 창이 닫힌다.

**AC-07** · GIVEN 열린 시트, WHEN 「닫기」·Esc·배경 클릭, THEN 시트가 닫히고 포커스가 연 칸으로 돌아온다. 시트가 열린 동안 뒤 화면은 조작되지 않는다.

**AC-08** · GIVEN 열린 시트, WHEN 폭을 측정하면, THEN 왼쪽 끝은 로고 중앙, 오른쪽 끝은 「로그아웃」 왼쪽 끝이고 480px 미만이면 전체 폭이다. 왼쪽 목록과 오른쪽 본문 사이에 세로선, 닫기 버튼은 시트 오른쪽 위에 있다.

**AC-08b** · GIVEN 시트가 열림, WHEN 현재 수치를 불러오면, THEN 목록 각 항목 오른쪽에 수치가 채워진다(규칙은 200일 때만, 실패하면 비움). 규칙을 삭제하면 규칙 수치도 줄어든다.

**AC-09** · GIVEN 시트에서 API가 401, WHEN 본문을 불러오면, THEN `/`로 이동한다. 429·5xx·네트워크 오류면 고정 문구와 「다시 불러오기」가 보인다.

**AC-10** · GIVEN 데이터가 있는 계정, WHEN 시트를 열면, THEN 요약 카드와 `role="img"` 그래프(요약 문장 `aria-label`)가 보이고 숫자는 API 응답에서 집계한 값과 같다.

**AC-11** · GIVEN 데이터가 없는 계정, WHEN 심사 건 기반 시트(리스크 점검·승인 현황·보고서)를 열면, THEN 카드는 0, 그래프 대신 빈 상태 안내와 「새 심사 건 만들기」가 보인다. 규칙 시트는 빈 상태 안내, 검색 시트는 결과 없음 문구를 보인다.

**AC-12** · GIVEN 서버가 HTML 문자열을 담은 기업명·규칙을 줌, WHEN 렌더링, THEN 태그로 해석되지 않고 글자로만 보인다(`innerHTML` 미사용).

**AC-13** · GIVEN 규칙 API가 503 `SERVICE_UNAVAILABLE_RULES`, WHEN 규칙 시트를 열면, THEN 데모 모드 안내가 보인다. 200이면 목록·그래프가 보이고 삭제는 두 단계 확인 뒤 `DELETE`를 부른다.

**AC-14** · GIVEN 이 변경, THEN 기능별 `tests/search_web_ui.test.mjs`, `reports_web_ui.test.mjs`, `rules_web_ui.test.mjs`(그리고 `reviews_summary_web_ui.test.mjs`, `feature_sheet_web_ui.test.mjs`)가 있고 `tests/*.test.mjs`와 pytest가 통과한다.

**AC-15** · GIVEN 03 패널, WHEN 처음 열면, THEN 띠 5개가 있고 `리스크 점검` 하나만 펼쳐져(`aria-expanded="true"`) 있으며 나머지 면은 `inert`다.

**AC-16** · GIVEN 03 패널, WHEN 다른 띠를 누르거나 Enter/Space/←→로 고르면, THEN 그 띠만 펼쳐지고 이전 띠는 닫힌다. 로그인 상태면 새로 펼친 띠의 미리보기를 채운다.

**AC-17** · GIVEN 로그인 상태, WHEN 03 패널이 보이면, THEN 닫힌 띠 아래에 짧은 수치가 채워지고 펼친 띠에 요약 문장·카드·그래프가 보인다. 심사 건 집계는 시트와 한 번만 부른다. 비로그인이면 API를 부르지 않고 설명만 보인다.

**AC-18** · GIVEN 로그아웃(`auth-state` anonymous), WHEN 로그아웃하면, THEN 수치와 미리보기가 비워진다.

**AC-19** · GIVEN 03 패널의 마크업, THEN 「열기」는 `a[data-feature]`(href `/?open=<기능>`)이고, 흰색 바탕의 버튼 스타일이 없으며 `innerHTML`을 쓰지 않는다.
