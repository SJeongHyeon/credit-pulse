# 그래프 이웃이 검색 1위일 때 저점수 재검토

## Why

- **페르소나**: 사업보고서 근거를 확인하는 기업여신 심사역.
- **문제**: 60번에서 그래프가 정답 원문을 검색 1위로 올렸지만 점수 0.6203이 현 임계값 0.6767 아래라 검색 채점기를 건너뛰었다. 현재 Supervisor가 거절해 최종 답변 개선으로 이어지지 않았다.
- **측정 지표**: 저점수 그래프 1위의 정답/오답 인용, 불필요한 작성, 추가 채점 호출 수, 검색·전체 응답 p95.

## Goal

- **성공 기준**: 60번의 정답 청크를 채점기로 확인하고 최종 정답 인용 1건을 만든다. 동결 v2의 오답 인용 증가 0건, 과잉 거절 증가 0건, 저점수 재검토의 추가 채점 호출은 해당 질문당 최대 1회다. 응답 p95는 기존 그래프 켠 모드보다 1초 이상 악화되지 않아야 한다.
- **Out of Scope**: 임계값 숫자 변경, 모델 변경, 재검색, 그래프 구조 변경, 지식 그래프, 기본 모드 켜기.

## What

1. 그래프가 추가한 원문 청크가 리랭커 1위이고 그 점수가 현재 임계값 미만이면 기존 검색 채점기를 한 번 호출한다.
2. 채점기가 1위 그래프 청크를 관련 근거로 고르고 충분하다고 확인하면 Supervisor가 작성 경로로 간다. 부족하거나 다른 청크만 골랐다면 거절한다.
3. 채점기 오류·키 없음·형식 오류는 충분으로 간주하지 않고 기존 저점수 거절로 끝낸다.
4. 그래프 후보가 1위가 아니거나, 그래프가 꺼졌거나, 점수가 임계값 이상이면 기존 경로를 그대로 쓴다.
5. 회사·연도·본문 해시·인용 검증은 기존 경로에서 계속 수행한다.

## How

- **설정**: `GRAPH_LOW_SCORE_REVIEW=true|false`, 기본 `false`, 다른 값은 설정 오류. `GRAPH_RETRIEVAL_ENABLED=true`에서만 효과가 있다.
- **출처 식별**: `ComboRetriever`가 그래프 확장 청크에만 `retrieval_method`의 `+graph:source` 꼬리표를 붙인다. 다른 청크는 기존 문자열을 유지한다.
- **검색 에이전트**: 1위 청크의 꼬리표와 점수로 이 분기만 판별한다. 기존 `grade_search_round`를 최대 1회 호출한다. 이 분기의 검색 보고에는 재검토 여부를 기록한다.
- **Supervisor**: 이 분기에서 채점 결과가 부족하거나 채점에 실패하면 작성 결정을 거절로 고친다. 충분이면 기존 guard 규칙대로 작성한다.
- **평가**: 한 번에 이 플래그만 변경한다. `GRAPH_RETRIEVAL_ENABLED=true`, `GRAPH_EXPANSION_LIMIT=1`을 양쪽에 고정한다. 60·62·26번 소수 탐침 뒤 동결 v2와 일상어 23건을 비교한다. 기존 결과·동결 파일은 수정하지 않는다.

## AC (Given-When-Then)

- **AC-01** GIVEN 그래프 이웃이 검색 1위·점수 미달 WHEN 옵션을 켜서 검색 THEN 채점기를 정확히 1회 호출한다.
- **AC-02** GIVEN 같은 청크를 채점기가 충분하다고 봄 WHEN Supervisor가 결정 THEN 작성 경로로 간다.
- **AC-03** GIVEN 채점기가 부족하다고 보거나 오류가 남 WHEN Supervisor가 결정 THEN 거절하고 작성하지 않는다.
- **AC-03a** GIVEN 채점기가 충분하다고 답했지만 1위 그래프 청크를 관련 청크로 고르지 않음 WHEN 보고를 검증 THEN 부족으로 보고하고 작성하지 않는다.
- **AC-04** GIVEN 이웃이 2위이거나 그래프가 꺼짐 WHEN 검색 THEN 저점수 채점 호출은 0회이고 기존 보고와 같다.
- **AC-05** GIVEN 허용되지 않는 설정 문자열 WHEN 설정을 읽음 THEN 기동이 설정 오류로 중단된다.
- **AC-06** GIVEN 동일 코퍼스·질문 WHEN 옵션만 바꿔 재측정 THEN 정답·오답 인용, 채점 호출, 응답 시간, 동결 해시가 기록된다.
