# Spec 비관련 질문 대응

## Why

- **페르소나**: FY2025 사업보고서 근거로 여신 심사 초안을 검토하는 심사역
- **문제**: 코퍼스 밖 회사·기간, 사업보고서 비공개 정보, 주제 밖 질문도 검색 결과를 근거처럼 제시할 위험이 있다.
- **측정 지표**: 비관련 15건의 올바른 거절·환각 위험, 관련 15건의 과잉 거절을 함께 기록한다.

## Goal

- 질문을 검색 전에 판별할 수 있는 경우, 검색·재작성·검증·저장 없이 거절한다.
- 거절 결과는 `outcome="refused"`와 기존 `refusal_reason`을 반환하고 `citations`는 빈 배열로 한다.
- API가 연결되는 단계에서는 거절도 HTTP 200으로 반환한다.
- **Out of Scope**: 주제 밖 자동 판별 및 새 LLM 분류기, 회사명 추출용 외부 서비스, 동결 평가셋 수정, API 엔드포인트 구현.

## What

**Happy Path**

1. 현재 코퍼스 manifest에서 회사명·사업연도 목록을 읽는다.
2. 질문의 회사명이 코퍼스 목록에 없으면 `CORP_NOT_IN_CORPUS`로 거절한다.
3. 질문의 연도·분기·보고서 종류가 코퍼스에 없으면 `PERIOD_NOT_IN_CORPUS`로 거절한다.
4. 위 조건이 아니면 기존 검색 흐름을 유지한다.
5. 검색 후 결과가 0건이면 기존 writer가 `ITEM_NOT_DISCLOSED`로 거절한다. 최상위 점수 임계값은 W2.10에서 모델별 설정값으로 정하며, 이번 작업에서는 구현하지 않는다.

**Edge Cases**

- 회사명 또는 기간을 찾지 못하면 추측으로 거절하지 않고 기존 검색 흐름으로 보낸다.
- `삼성전자 차입금 만기 구조 알려줘`처럼 보고서 지정 없이 회사명 후보로 시작하면 사전 판별에서 회사를 확정하지 않는다.
- 질문 앞의 `회사명(의) 2024년 사업보고서`처럼 요청 보고서의 연도가 명시되면 FY 표기와 같은 기준으로 비교한다. 문장 속 다른 연도는 요청 보고서의 연도로 해석하지 않는다.
- 회사명을 비교할 때 양쪽의 법인 표기 `(주)`, `㈜`, `주식회사`와 공백을 정리한다.
- 코퍼스 목록은 코드 상수가 아니라 manifest에서 읽는다.
- 거절하면 `citations`와 `draft_items`를 비운다.
- 거절된 질문은 retriever, rewriter, verifier, human_approval, save_memo를 호출하지 않는다.
- 관련 질문은 사전 판별 규칙만으로 거절하지 않는다.

## How

- 기존 사유 코드 `OUT_OF_DOMAIN`, `CORP_NOT_IN_CORPUS`, `ITEM_NOT_DISCLOSED`, `PERIOD_NOT_IN_CORPUS`를 재사용한다.
- 질문 판별은 결정적 문자열 규칙과 manifest 기반 목록 조회만 사용하며 LLM을 호출하지 않는다.
- 없는 회사·없는 기간은 supervisor 이전 또는 supervisor에서 판별한다.
- `ITEM_NOT_DISCLOSED`는 기존 계약대로 검색 결과가 0건일 때만 사용한다. 검색 결과 최상위 `score`를 이용한 거절 임계값은 `SPEC.md`의 모델별 설정값이며, W2.10에서 사전 등록·구현한다.
- 거절 문구는 사유별로 고정한다. 근거가 없다는 사실과 이유를 알리고, 존재하지 않는 출처를 제시하지 않는다.

## AC

**AC-02 코퍼스 밖 회사 거절**

- GIVEN: manifest에 없는 회사명을 포함한 질문
- WHEN: 그래프를 실행
- THEN: `CORP_NOT_IN_CORPUS`으로 거절하고 검색기를 호출하지 않음

**AC-03 코퍼스 밖 기간 거절**

- GIVEN: 현재 manifest에 없는 FY2024 또는 분기 보고서 질문
- WHEN: 그래프를 실행
- THEN: `PERIOD_NOT_IN_CORPUS`으로 거절하고 검색기를 호출하지 않음

**AC-04 검색 결과 없음 거절**

- GIVEN: 검색과 재작성 상한을 마친 뒤 `retrieved_chunks`가 빈 목록
- WHEN: writer가 결과를 판정
- THEN: `ITEM_NOT_DISCLOSED`로 거절하고 citations와 draft_items는 빈 배열

**AC-05 과잉 거절 방지**

- GIVEN: 코퍼스 회사·기간을 요청하는 관련 질문
- WHEN: 사전 판별을 실행
- THEN: 사전 판별에서 거절하지 않고 기존 검색 흐름으로 진행
