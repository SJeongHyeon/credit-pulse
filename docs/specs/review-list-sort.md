# 심사 건 목록 정렬

## Why

심사역은 심사 건을 만든 시점이나 기업명으로 찾아야 한다. 2번 기업 검색과 같은 메뉴를 사용한다.

## Goal

- 최신순, 오래된순, 가나다순 세 가지를 제공한다. 기본값은 최신순이다.
- 첫 페이지와 다음 페이지를 같은 기준으로 정렬한다.
- 범위 밖은 정렬 선택 저장과 판정 규칙 정렬이다.

## What

- 심사 건 제목 바로 오른쪽에 아이콘, 현재 정렬 기준, 펼침 표시를 배치한다. 전체 삭제 버튼은 제목 행 오른쪽 끝에 둔다.
- 최신순과 오래된순은 심사 건 생성 시각 기준이다. 가나다순은 기업명을 기준으로 한글을 먼저 표시한다.
- 정렬을 바꾸면 첫 페이지부터 불러온다. 목록에서 새 심사 건을 만든 뒤에도 현재 정렬 기준을 적용한다.

## How

- 2번 기업 검색의 정렬 메뉴 마크업, 스타일, 마우스 및 키보드 제어를 재사용한다.
- `GET /api/v1/reviews`는 `sort=recent|oldest|name`을 받고 로그인 사용자의 정렬된 목록을 반환한다. 기본값은 `recent`다.
- 페이지는 선택한 정렬 기준과 마지막 건의 정렬 키 및 ID를 커서로 이어 간다. 잘못된 커서는 400을 반환한다.

## AC

- GIVEN 3번 화면 WHEN 목록을 열면 THEN 심사 건 제목 오른쪽에 최신순 메뉴가 보인다.
- GIVEN 목록이 두 페이지 이상 WHEN 오래된순 또는 가나다순을 고르면 THEN 해당 순서의 첫 페이지를 받고, 더 보기에서 같은 순서의 다음 페이지를 받는다.
- GIVEN 오래된순 또는 가나다순 WHEN 새 심사 건을 만들면 THEN 현재 정렬 기준으로 목록을 다시 읽는다.
