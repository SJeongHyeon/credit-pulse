# 사업연도 질의 해석

## Why

- **페르소나**: FY2025 사업보고서를 조회하는 기업여신 심사역
- **상황**: 사용자가 `작년`, `올해`, `25년`, `2026년`처럼 기간을 달리 표현한다.
- **문제**: 현재 회사에 FY2025 문서가 하나뿐이면 명시한 FY2026도 FY2025로 검색할 수 있다.
- **측정 지표**: 지원·미지원 기간의 검색 호출 수와 `corp_code`·`fiscal_year` 필터 정확도

## Goal

- 기준 날짜 2026-11-05를 주입한 기간 사례에서 지원 연도는 정확한 필터로 검색하고 미지원 연도는 검색 0회로 거절한다.
- `classify_question`과 `resolve_target`이 같은 기준 날짜와 정규화 규칙을 사용한다.
- 기존 `FY2025 사업보고서에서 2024년 수치` 질문의 검색 대상은 FY2025로 유지한다.
- **Out of Scope**: FY2024 수집, 여러 사업연도의 비교 답변, 접수연도 기반 검색, LLM 질의 재작성 변경

## What

**Happy Path**
1. Supervisor가 요청마다 한국 시간 기준 날짜를 한 번 확정한다.
2. 기간 표현을 절대 사업연도로 바꾸고 보고서 제목에 붙은 사업연도를 우선한다.
3. 회사·연도가 manifest에 있으면 해당 필터를 검색기로 보낸다.
4. 연도가 없고 해당 회사 문서가 하나면 기존처럼 그 문서를 선택한다.

**Edge Cases**

| 상황 | 처리 |
|---|---|
| `올해`·`2026년`이 FY2025 전용 코퍼스에 없음 | `PERIOD_NOT_IN_CORPUS`, 검색 0회 |
| `작년과 재작년` 중 FY2024가 없음 | `PERIOD_NOT_IN_CORPUS`, 검색 0회 |
| `FY2025 사업보고서에서 2024년 수치` | 보고서 사업연도 FY2025를 선택 |
| `25년 만기` | 두 자리 기간을 사업연도로 치환하지 않음 |
| `내년 환율 예측` | 기간 판정으로 주제 밖 질문을 선점하지 않음 |
| 회사나 연도 대상이 둘 이상이라 하나로 결정 불가 | 기존 `target_required` 경로로 보냄 |

## How

- `backend/graph/refusal.py`: 공통 기간 추출 함수로 정규화·보고서 연도 우선순위·명시적 연도 검사를 모은다. `classify_question`과 `CorpusCatalog.resolve_target`은 동일한 `reference_date`를 받는다.
- `backend/graph/build.py`: Supervisor에서 한국 시간 날짜를 한 번 생성해 두 함수에 전달한다.
- manifest 회사·연도 쌍이 없는 명시적 질문은 문서가 하나뿐이어도 다른 연도로 대체하지 않는다.
- `evals/dataset_v1.jsonl`, `evals/dataset_v2.jsonl` 및 동결 매핑은 수정하지 않는다.

## AC

- **AC-01** GIVEN FY2025 한 건과 기준일 2026-11-05 WHEN `작년`을 묻는다 THEN FY2025 필터로 검색한다.
- **AC-02** GIVEN 같은 코퍼스 WHEN `올해`, `2026년`, `재작년`을 묻는다 THEN `PERIOD_NOT_IN_CORPUS`이며 검색 호출은 0회다.
- **AC-03** GIVEN 같은 코퍼스 WHEN `25년 매출액`을 묻는다 THEN FY2025 필터로 검색한다.
- **AC-04** GIVEN `FY2025 사업보고서에서 2024년 차입금` WHEN 분류한다 THEN FY2025 대상이며 기간 거절이 아니다.
- **AC-05** GIVEN 동결 v2의 `내년 환율 예측` WHEN 기간 분류한다 THEN 기간 거절로 분류하지 않는다.

## 1-3 접수연도와 다중 연도 확인

- 접수·제출·공시 시점을 연도로 지정한 질문은 사업연도로 단정하지 않는다. 검색 없이 `target_required`와 사업연도 지정 안내를 반환한다.
- 명시한 두 사업연도 중 하나가 코퍼스에 없으면 기존 `PERIOD_NOT_IN_CORPUS`를 유지한다. 둘 다 있어도 이번 범위의 단일 연도 검색으로 비교 답변을 만들지 않고, 한 사업연도 지정 요청을 반환한다.
- `FY2025 사업보고서의 접수일`처럼 FY가 명확한 질문은 위 확인 경로에 넣지 않는다.
- **Out of Scope**: 접수연도 → 사업연도 자동 추론, 복수 사업연도 검색·비교 답변, LLM 분류 호출.

## 1-4 추가 AC

- **AC-06** GIVEN FY2025 코퍼스와 기준일 2026-11-05 WHEN `올해 접수된 사업보고서`를 묻는다 THEN 사업연도를 지정해 달라는 `target_required` 응답이며 검색 0회다.
- **AC-07** GIVEN FY2025 코퍼스 WHEN `FY2025 사업보고서 접수일`을 묻는다 THEN FY2025 필터로 검색한다.
- **AC-08** GIVEN FY2024·FY2025 모두 있는 회사 WHEN `작년과 재작년 비교`를 묻는다 THEN 단일 연도 지정 요청이며 검색 0회다.
- **AC-09** GIVEN FY2025만 있는 회사 WHEN 같은 비교를 묻는다 THEN `PERIOD_NOT_IN_CORPUS`이며 검색 0회다.
