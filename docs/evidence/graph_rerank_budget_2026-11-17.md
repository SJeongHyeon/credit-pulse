## 품질 위험과 다음 측정

- 150번 기록에서 새 한도로 제외되는 RRF 41~49위 청크가 과거 최종 검색 상위 10개에 들어간 사례가 일상어 11개, 동결 v2 6개 있다. 이 중 실제 정답 인용 영향은 새 리랭커 호출 후에만 판정할 수 있다.
- 164번 60번도 제외될 청크 1개가 과거 최종 검색 상위 10개에 있었다. 62번은 없었다. 이는 60번의 정답 이웃 유지 여부와 별개다.
- 입력 글자 감소는 **속도 개선의 보증이 아니다**. 외부 리랭커 시간과 전체 응답 시간을 전후 실측해야 한다.
- 승인 후 소규모 질문 10회 실행으로 검색 후보, 정답/오답 인용, 지연, 알려진 비용을 비교한다. 통과해도 전체 평가 23+50문항의 별도 승인과 측정 전에는 그래프 기본값을 켜지 않는다.

## 승인된 전체 평가: 진행 중 기록

- 사용자가 전체 일상어 23문항·동결 v2 50문항의 전후 평가를 승인했다. 전달한 예상 비용은 $1.0~1.5, 알려진 비용 중단 기준은 $2.50이다.
- 기본 샌드박스에서 OpenRouter DNS 조회가 차단되어 첫 시도는 첫 문항 이전에 HTTP 503 연결 실패로 중단됐다. 허용된 네트워크에서 키 없이 TCP 연결이 확인된 뒤 실제 평가를 시작했다.
- 완료된 첫 묶음 `graph167_full_paraphrase_qall_budget_default`: 23문항, 정답 인용 13·오답 인용 2·과잉 거절 8, 첫 검색 Hit@10 20/23, 리랭커 입력 1,199,450자, 알려진 비용 $0.204004, 비용 미기록 호출 0.
- 두 번째 23문항 묶음은 Voyage 서버와의 연결이 도중에 끊겨 중단됐다. 완료 요약이 없으므로 해당 묶음의 결과·비용을 주장하지 않는다. 이후 동결 v2는 실행되지 않았다.
- 반복 호출 낭비를 줄이기 위해 완료된 첫 묶음은 `--resume`으로 재사용하고, 남은 123회 질문 실행은 질문 5개씩 결과 파일을 남기도록 러너만 변경했다. 검색 코드, 모델, 임계값, 평가 입력은 변경하지 않았다. 키 없는 드라이런에서 총 146회 질문 계획을 확인했다.
- 이어서 일상어 40+1 조건 23문항이 5개 파일로 완료됐다. 요약 합계는 정답 인용 15·오답 인용 1·과잉 거절 6, 알려진 비용 $0.140520이다. v2 앞 10문항의 전후 파일도 완료됐다.
- 다음 v2 5문항 묶음은 전부 비관련 질문이어서 검색 적중률 요약의 분모가 0이 되는 기존 러너 제한으로 중단됐다. 질문 실행 후 요약 실패라 이 묶음의 비용은 결과 파일에서 확인할 수 없다.
- v2의 완료된 앞 10문항은 그대로 두고, 남은 40문항을 각 묶음에 관련 질문이 최소 1개 있도록 재배치했다. 50개 ID가 한 번씩만 나오고 전체 전후 실행 수가 146이며, 모든 v2 묶음에 검색 평가 대상 관련 질문이 있는지 키 없이 확인했다. 평가 입력과 판정 기준은 그대로다.

시간 p50은 중앙값, p95는 오름차순에서 `ceil(0.95×n)`번째 표본이다. 검색 노드 시간은 실제 retriever 노드가 실행된 문항만 센다(일상어 각 23, v2 각 34). 전체 응답은 모든 문항을 센다. 동결 v2 검색 지표의 관련 문항은 검색 평가 파생셋에 포함된 23개다. 표의 알려진 비용 합계는 **$0.831305**이고 완료된 파일의 비용 미기록 호출은 0이다. 중간에 실패한 Voyage 묶음과 요약 오류 묶음의 사용량은 결과 파일이 없어 이 합계에 포함되지 않는다.

질문별로 일상어 1번은 기존 정답 인용에서 새 조건 거절로 악화됐다. 15·39·40번은 거절에서 답변으로 바뀌었다. 동결 v2에서는 1번이 새 조건에서 인용을 확보해 정답 인용 총계가 1건 늘었지만, 36번은 인용 4개에서 2개로 줄었다. 동결 v2 50문항 중 12개는 최종 검색 ID가 달라졌고 답변 결과는 생성 모델 변동의 영향을 받을 수 있다. 일상어 60번은 두 조건 모두 거절했다.

**판정: 후보 40개 설정과 그래프 검색의 기본 채택을 보류한다.** 입력 글자 감소와 동결 v2 정답 인용 유지·개선은 확인됐다. 그러나 사전 등록한 검색 p95 비악화 기준은 일상어 +6.1ms, 동결 v2 +228.4ms로 둘 다 실패했다. 시간 분포가 외부 호출의 변동에 영향을 받아 반복 측정도 필요하다. 이전 150번 그래프 꺼짐 기록의 동결 v2 정답 인용은 24/25로 이번 새 그래프 조건과 같고, 당시 일상어는 18/23으로 이번 15/23보다 높다. 서로 다른 시점의 실행이므로 직접적인 A/B 증거로 취급하지 않는다. 그래프 기본값은 계속 꺼져 있다.

150번에서 예전 그래프 설정(이웃 최대 10개)의 끔/켬 전체 비교는 이미 완료했다(`docs/evidence/graph_retrieval_2026-11-13.md`). 다음 실험은 **새 40+1 설정**과 그래프 끔을 직접 비교하기 위해 `docs/specs/graph-adoption-gate.md`와 `evals/PREREGISTER.md`에 사전 등록했다. `scripts/run_graph_limit_smoke.py --adoption-full --dry-run`으로 그래프 끔/켬의 23+50문항씩 총 146회, 5문항 이하 묶음 30개를 키 없이 확인했다. 이전 167번 결과를 새 A/B 결과로 재사용하지 않는다. **새 실제 API 비용에 대한 별도 사용자 승인 전에는 실행하지 않는다.**
