## 첫 배포에서 고친 것 (PR #124)

1. 로그인 버튼 무반응: Cloud Run 프록시 헤더를 믿지 않아 템플릿 링크가 `http://`가 됐고 브라우저가 혼합 콘텐츠로 스크립트를 막았다 → uvicorn `--proxy-headers --forwarded-allow-ips *`.
2. 질의마다 500 `DuplicatePreparedStatement`: Supabase 트랜잭션 풀러(6543)에서 그래프용 연결 풀이 prepare를 켜 두었다 → `prepare_threshold=None`. 로컬 pgbouncer(transaction, `max_prepared_statements=0`)로 재현·수정 확인.
3. Cloud Run 환경변수 누락(`DATABASE_URL`·키): 콘솔에서 넣음. README 배포 절에 PowerShell 따옴표 주의와 함께 적음.
