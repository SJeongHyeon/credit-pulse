# 주제서: 여신심사역용 DART 리스크 체크리스트 RAG

1조 · 박민영(팀장), 류승민, 서정현 · 10/29 주제서 제출본
목표 직무와 산업: LLM·RAG 엔지니어 / 금융(추천 산업)

## 1. 누가, 어떤 업무에서

- 사용자: 은행·캐피탈의 기업여신 심사역 (신용평가사 애널리스트도 대상)
  - **11/13 갱신: 우선 대상을 저축은행·캐피탈(2금융권)의 기업여신 심사역으로 좁혔다.** 은행 심사역과 신용평가사 애널리스트는 같은 업무를 하지만 우선 대상이 아니다(이유는 5장).
- 업무 장면: 신규·연장 심사 때마다 차주 기업의 사업보고서를 읽고 심사의견서의 '사업 위험' 칸과 체크리스트(소송, 채무보증·담보, 고객 집중도, 환율·원재료 위험)를 채우는 일

## 2. 무엇을 묻는가

1. "효성중공업 FY2025 우발부채와 연결주석의 담보·보증 내역을 상대방·금액별로 정리하고, '보증·담보' 항목 판정 초안을 내줘"
2. "한일철강 FY2025와 FY2024 사업보고서의 위험 서술·주요 고객 의존도 문장 중 새로 생기거나 빠진 것은?"
3. "조선사(한화오션, 대한조선 등)의 환율·선수금 위험 서술과 헤지 방식을 근거 위치와 함께 비교해줘"

## 3. 지금은 어떻게 하는가

- DART 뷰어에서 Ctrl+F로 찾아 직접 발췌하고 요약한다(**가설**, 현업 검토 예정).
- 불편: XI장이 '주석 ○ 참조'로 넘겨 여러 곳을 오가야 하고, 전년 대비 바뀐 문장은 두 보고서를 사람이 맞대어 봐야 한다.

## 4. 범용 챗봇과 무엇이 다른가

1. 답마다 근거 위치(접수번호 rcept_no + 장·주석 번호)를 달고, 코드로 원문과 대조한다.
2. 중소·중견 차주의 주석과 XI장은 뉴스·IR에 잘 나오지 않아 웹 검색 챗봇이 닿기 어렵다(**가설**, 같은 질문 5개 비교표로 검증 예정).
3. 전년 보고서와 문단 단위로 비교한다.
4. 근거가 부족하면 주석으로 다시 검색하고, 판정은 심사역이 승인·수정한 뒤에만 '심사 메모'로 저장한다(interrupt). 고친 판정은 Store에 남아 다음 심사에 반영된다.

## 5. 누가 쓰고 누가 지불하는가

- 사용자: 여신심사역
- **겨냥할 기관 유형(11/13 팀 결정): 저축은행·캐피탈(2금융권) 우선.** 이유: ① 대형 은행은 같은 업무를 자체 구축했다(신한은행 여신심사지원 Agent, 2026-03) ② 2금융권은 외부 업체의 대출 AI를 공급받기 시작했다(애큐온저축은행 2026-07, 웰컴저축은행 2026-08) ③ 우리와 가장 가까운 업무 과제가 캐피탈에서 나왔다(JB우리캐피탈, DART와 LLM으로 공시 분석·심사 보고서 작성, 2026년 상반기). 근거는 [국내 발주 및 도입 사례](evidence/domestic_purchase_2026-11-13.md), 판정표는 [시장 근거 문서](deliverables/market_buyer_evidence_2026-11-12.md).
- **지불 주체는 여전히 가설이다.** 기관 유형은 정했지만, 그 기관에서 누가 예산을 내는지는 실무자에게 확인하지 못했다. 가설: 2금융권의 여신기획·리스크관리 부서가 도입을 검토하고 디지털·IT 부서가 기술을 협의한다. 국내 금융기관의 유사 발주 예산과 역할, AI 플랫폼 계약은 [국내 발주 및 도입 사례](evidence/domestic_purchase_2026-11-13.md)에 정리했다. Credit Pulse의 구매 예산·최종 승인권자·도입 의향은 미확인이다.
- 채용 근거: 금융권 채용 공고 중 LLM·RAG·생성형 AI 언급 30건(사람인·잡코리아, 2026-08-01~10-28, 중복 제거). 직무명·주요업무·필수요건에 들어간 공고는 14건. 원티드는 자동 수집 금지로 제외, 마감 공고 제외라 하한값. 50건 기준에는 못 미친다.
- 외부 시선 1명 검토는 D10(11/13)까지 받는다.

## 6. 코퍼스

- 출처: OpenDART 공시서류원본파일 API `document.xml`, 대상 목록은 공시검색 API `list.json`
- 범위: FY2025 사업보고서(2026-03 제출) 100사, II·IV·XI장 + 연결주석 1벌. FY2024는 비교용 30사이며, 90% 이상 겹치는 청크는 G3 집계에서 제외
- 1만 청크 근거: B-100 v7 로컬 재빌드에서 본문 SHA-256 기준 고유 eligible 청크 51,495개를 확인했다. 최종 업종별 100+30 목록 확정 후 같은 기준으로 다시 측정한다.
- 이용 조건: 공공데이터로 활용 제한 없음, 재배포 책임은 이용자(OpenDART FAQ 9번). 1인 1키, 제3자 이용 금지(이용약관 제19조). 데모 모드는 API를 부르지 않고 스냅샷만 쓴다.
