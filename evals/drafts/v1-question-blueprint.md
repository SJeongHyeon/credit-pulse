# v1 질문 초안 블루프린트

## 목적과 범위

이 문서는 v1 평가셋의 질문 초안을 준비하기 위한 배분표와 작업 절차다. 현재 코퍼스 대상 기업 목록과 `corpus_version`이 없으므로 실제 기업명 기반 질문, `expected`, `gold_chunks`는 이 문서에 작성하지 않는다.

### v2 증분 관련 질문의 비교 유형

v1은 FY2025 코퍼스만으로 동결하므로, 두 시점 또는 두 회사를 모두 근거로 해야 하는 비교 질문은 넣지 않는다. FY2024 코퍼스를 확보한 뒤 v2에서 추가하는 관련 10건에는 다음을 각각 최소 2건 포함한다.

- **전년 대비 변경**: 같은 회사의 FY2024·FY2025 공시를 비교해 새로 생기거나 사라진 위험 서술·수치를 묻는다.
- **회사 간 비교**: 같은 연도·체크리스트 항목에서 두 대상 회사의 위험·수치를 비교해 묻는다.

두 유형은 질문마다 비교 대상 회사·연도와 양쪽 근거를 모두 기록할 수 있을 때만 v2 동결 후보에 넣는다.

## 질문 작성 규칙

- 질문 작성자 서정현은 `gold_chunks`와 `expected`를 열람하지 않는다.
- 대상 기업 목록이 생긴 후 관련 질문에는 목록 내 기업을 사용한다.
- `unknown_entity` 질문에는 목록 밖 기업을 사용한다.
- `wrong_period` 질문에는 해당 회사의 코퍼스에 없는 연도 또는 분기를 사용한다. FY2024 코퍼스를 추가한 뒤에는 그 회사에 FY2024가 실제로 있는지 먼저 확인하고, 있는 경우 다른 미수집 기간을 사용한다.
- 류승민이 `expected`, `gold_chunks`, `why`를 판정한다.
- 류승민이 동결 전 형식·분포·역할 분리를 검수하고 최종 확인한다. 박민영은 측정 뒤 결과를 재검토한다.
- 질문은 문항별로 하나의 점검 의도와 기업·기간을 명확히 표현한다. 답변 문구나 근거 청크의 표현을 추정해 질문에 넣지 않는다.
- 관련 15건에는 공시 여부 확인만 몰지 않고, 보증 금액·차입금 만기 같은 수치 추출, XI장과 주석의 참조를 따라가는 질문, 답이 `해당사항 없음`인 관련 질문을 각각 최소 1건 포함한다.

## 코퍼스 준비 후 실제 작성 절차

1. W0.6 대상 기업 목록이 확정되면 서정현이 위 배분표를 따라 실제 질문 초안 30건을 작성한다.
2. `data/manifest.jsonl`에서 대상 기업과 수집 문서 연도를 확인한 뒤, 류승민이 각 문항의 `expected`, `gold_chunks`, `why`를 독립적으로 판정한다.
3. 동결 직전에 각 문항의 `corpus_version`을 채운다.
4. 형식과 분포를 검수한다. 관련 15건·비관련 15건인지, 비관련 네 유형이 각각 배분 수를 만족하는지, 필수 메타데이터가 있는지 확인한다.
5. 검수를 통과한 문항으로 `dataset_v1.jsonl`을 확정한 뒤 동결 절차를 실행한다.
6. 측정 뒤 박민영이 결과를 재검토한다.
